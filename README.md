# 🐍 Snake — Rust / WebAssembly

A professional Snake game built with **Rust** and compiled to **WebAssembly** via
[wasm-pack](https://rustwasm.github.io/wasm-pack/) and
[wasm-bindgen](https://rustwasm.github.io/wasm-bindgen/).

## Features

- ✅ Pure-Rust game logic (zero JS game code)
- ✅ 36 unit tests — all passing
- ✅ Canvas-based renderer with smooth 60 fps loop
- ✅ Speed progression as the score increases
- ✅ High-score persistence via `localStorage`
- ✅ Keyboard (arrow keys + WASD) and mobile D-pad controls
- ✅ Pause / resume
- ✅ Game-over screen with restart

## Project layout

```
├── Cargo.toml          # Rust crate config (lib + cdylib)
├── src/
│   ├── lib.rs          # WASM entry-point & panic hook
│   ├── game.rs         # Game struct + all game logic (wasm_bindgen exports)
│   └── snake.rs        # Snake entity, Direction, Point
└── www/
    ├── index.html      # Game page
    ├── style.css       # Dark-theme CSS
    ├── index.js        # JS host: game loop, rendering, input
    └── pkg/            # 🔧 generated by wasm-pack (git-ignored)
```

## Quick start

### Prerequisites

- [Rust toolchain](https://rustup.rs/) (stable)
- [wasm-pack](https://rustwasm.github.io/wasm-pack/installer/)

```bash
cargo install wasm-pack
rustup target add wasm32-unknown-unknown
```

### Build

```bash
wasm-pack build --target web --out-dir www/pkg
```

### Run locally

Serve the `www/` directory with any static file server, e.g.:

```bash
# Python 3
cd www && python3 -m http.server 8080

# Node (npx)
cd www && npx serve .
```

Then open <http://localhost:8080> in your browser.

### Test

```bash
# Native unit tests (fast, no browser needed)
cargo test
```

## Architecture

All game logic lives in **Rust**:

- `Snake` — a `VecDeque<Point>` of body segments; handles movement, growth, and
  self-collision detection.
- `Game` — owns a `Snake` and a food `Point`; exposes `tick()` / `step()` /
  `key_down()` to JavaScript.

The **JavaScript** host is kept intentionally thin:
- Boots the WASM module, creates a `Game`, and schedules a `requestAnimationFrame`
  loop.
- On each frame it calls `game.tick()` then reads `game.cells()` (a `Uint8Array`)
  and redraws the canvas.
- Keyboard and touch events are forwarded to `game.key_down(key)`.
